## 🎉 Overview

Version 0.3.3 introduces `DartmouthDecisions`, a new component for **Decision models**: models that answer typed questions about text or structured state and return probabilities and confidence instead of free-form text. The release also adds Decision-specific exception types and a model listing for Decision models.

> [!IMPORTANT]
> The Decision model endpoints will go live with the Dartmouth Chat release scheduled for **November 5, 2026**. Until then, `DartmouthDecisions` and `DartmouthDecisions.list()` will fail against the default endpoint.

> [!TIP]
> New in the [LangChain Dartmouth Cookbook](https://dartmouth.github.io/langchain-dartmouth-cookbook): the [Decision models recipe](https://dartmouth.github.io/langchain-dartmouth-cookbook/18-decision-models.html) is a hands-on walkthrough of `DartmouthDecisions`, covering classifying abstracts by research method, combining several questions in one request, and rating against a rubric.

## ✨ New Features

### `DartmouthDecisions` (#55)

`DartmouthDecisions` sends one or more typed questions about an input and returns structured answers. A single request can combine three question types:

| Question type | Use it for | Answer |
|---|---|---|
| `Noul` | Binary yes/no judgments | Probability that the answer is yes (`0.0`–`1.0`) |
| `Choice` | Picking one label from an unordered set | Selected label, per-label probabilities, confidence |
| `Score` | Rating against an ordered rubric | Expected score (may be fractional), per-level probabilities |

```python
from langchain_dartmouth.decisions import Choice, DartmouthDecisions, Noul

decisions = DartmouthDecisions()  # defaults to "cloudflare.clef"

response = decisions.invoke(
    {
        "state": "Stripe fails whenever I connect my account. Production is down!",
        "questions": {
            "urgent": Noul(instructions="Does this message require an urgent response?"),
            "department": Choice(
                instructions="Which team should handle this request?",
                criteria={
                    "billing": "Payment, invoice, or subscription issues.",
                    "technical": "Product bugs or integration failures.",
                    "sales": "Pricing or purchasing questions.",
                },
            ),
        },
    }
)

print(response.nouls["urgent"].noul)
print(response.choices["department"].choice, response.choices["department"].confidence)
```

- Authenticates with your Dartmouth Chat API key (`dartmouth_chat_api_key` or the `DARTMOUTH_CHAT_API_KEY` environment variable), like `ChatDartmouth`
- Supports `invoke` and `ainvoke`. You can pass your own `httpx2.Client` / `httpx2.AsyncClient` and set a `timeout` (default `30.0` seconds)
- `DartmouthDecisions.list()` returns the available Decision models
- The request and response types (`Choice`, `Score`, `Noul`, `NoulCriteria`, `Question`, `State`, `ClassifierRequest`, `ClassifierResponse`, `Usage`) are re-exported from `langchain_dartmouth.decisions`, so you don't need to import from the upstream package

### Decision Model Listing

New `DecisionModelListing` class in `langchain_dartmouth.model_listing`. It uses the same host, authentication, and `ModelInfo` response shape as `CloudModelListing`, but queries the Decision model endpoint.

### Configurable Endpoint

The Decision model base URL defaults to the same value as `CLOUD_BASE_URL`. To point it somewhere else, set the `LCD_DECISIONS_BASE_URL` environment variable or pass `inference_server_url` to `DartmouthDecisions`.

## ⚠️ Error Handling

`DartmouthDecisions` only raises exceptions defined in `langchain_dartmouth.exceptions`. Upstream `TypeSafe*` exceptions are never exposed:

| Situation | Exception |
|---|---|
| Invalid API key | `InvalidKeyError` (existing) |
| Unknown model | `ModelNotFoundError` (existing) |
| Rate limited | `DecisionRateLimitError` (**new**), with `.retry_after_ms` |
| Any other API failure (bad request, timeout, connection, server error, ...) | `DecisionAPIError` (**new**) |

`DecisionRateLimitError` subclasses `DecisionAPIError`, so `except DecisionAPIError` catches both:

```python
from langchain_dartmouth.exceptions import DecisionAPIError, DecisionRateLimitError

try:
    response = decisions.invoke(request)
except DecisionRateLimitError as e:
    retry_later(delay_ms=e.retry_after_ms)
except DecisionAPIError as e:
    log.error("Decision request failed: %s", e)
```
